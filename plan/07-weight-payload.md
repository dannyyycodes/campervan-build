# 07 — Weight & payload budget

**Why:** a 3500kg Ducato has a fixed payload (~1100–1500kg depending on model). Battery + water + build + Surron + gear adds up fast. Overweight = illegal + unsafe + ruins handling. Track every heavy item.

## To build (⏳)
A running table: kerb weight → MAM 3500kg → payload. Subtract:
- Build (timber, ply, insulation, cladding) — est.
- Battery bank (LiFePO4 ~10–13kg per 100Ah) + inverter + cabling
- Water (1L = 1kg; full fresh can)
- Surron (~50–67kg) + tow rack
- Kit, tools, food, person(s)

Goal: stay comfortably under MAM with margin. Flag the Surron + battery + water as the big three.
