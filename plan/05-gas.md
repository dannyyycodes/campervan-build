# 05 — Gas (single hob + safety)

## ⚠️ The key fork (sign-off): portable vs fixed = the whole gas-regime switch
- **Portable** (a non-fixed appliance fed from a bottle/cartridge via hose) → **BS EN 1949 fixed-install rules DO NOT apply, no Gas-Safe cert needed.** Correct for the minimalist brief.
- **Fixed** (hob bolted into a unit) → fixed gas installation: BS EN 1949 applies, Gas-Safe (LPG+LAV) sign-off expected by insurers/sites/ferries.
- **DVLA caveat:** a single-burner portable hob **likely fails DVLA "Motor Caravan" reclassification** (DVLA expects a fixed hob alongside seat/sleep/storage/window). **You can't have both "no fixed gas" AND the logbook reclass.** → Decide: reclass yes/no?

## Recommended (matches "occasional warm drinks", stays portable)
- **Cadac Safari Chef 2 (~£100)** — runs off a refillable bottle, Power Pak, or EN417 cartridge; doubles as outdoor grill. **OR** a simple **EN417 butane/propane cartridge stove (~£20–30)** (butane weak below ~5°C — propane mix better for UK winter).
- Fuel: **EN417 cartridges** = zero install, perfect for low use. A swappable Calor bottle in a vented locker only if cartridge waste annoys (then it's no longer "minimal").

## Safety spec — non-negotiable even when portable (LPG in a sleeping space)
| Item | Spec |
|---|---|
| Regulator | 30 mbar LPG |
| Leak test | in-line bubble tester / leak spray — no bubbles in 30s |
| **Gas drop-out vent** | LPG is **heavier than air** → low-level floor vent so leaks drain OUT; ≥2% locker floor area, not blocked by the bottle |
| Hose | date-stamped LPG hose (~5yr life), HP runs ≤400mm |
| Hob FFD | flame-failure device (cuts gas if flame blows out) — Cadac/Klarsten have it |
| **CO alarm** | EN 50291-2 (RV-rated), mounted **HIGH** near sleeping |
| **LPG alarm** | EN 50194, mounted **LOW** |
| Locker (if bottle) | sealed, externally vented, hand-undo straps |

**Rule: CO + smoke HIGH, LPG LOW.**

## Ventilation interaction
Gas dumps **~450mL water/hr** + CO → always **crack 2 vents + run the roof fan on exhaust + lids on pans** when lit. See [02-ventilation](02-ventilation.md). Fit gas AFTER electrics so the alarms are live first.

## Alternative worth weighing
**Induction + the inverter** removes gas entirely — no CO, no combustion water, no LPG locker/regs. Costs ~150Wh/boil off the battery instead. (See kettle decision in [03-electrical](03-electrical.md).)
