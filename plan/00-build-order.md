# 00 — Build order & sequence

The order pros follow. Each step locks in the one before; doing them out of order means ripping work out.

1. **Strip & clean** — empty the van to bare metal. Remove ply lining/load anchors.
2. **Rust treat & anti-corrosion** — grind/treat any rust, cavity-wax the box sections (Bilt Hamber / Dinitrol). Do this NOW — you can never reach it again once insulated.
3. **Sound deadening (optional, targeted)** — butyl pads on large flat panels (door skins, wheel arches) to kill drum. NOT a full cover (weight, off-gassing — non-toxic brief avoids Dynamat; use a minimal butyl).
4. **Insulation — first fix** — battens fixed to ribs, sheep wool into every cavity/rib, around arches. See [01-insulation](01-insulation.md). Breathable build — no sealed vapour trap.
5. **Electrical — first fix** — run ALL cables now while walls are open: battery↔devices, solar, lights, fan, switches, the bed kill-switch. Leave tails. See [03-electrical](03-electrical.md).
6. **Ventilation cut-in** — roof fan hole + passive vents cut and sealed now. See [02-ventilation](02-ventilation.md).
7. **Flooring** — battens + insulation between, breathable membrane, birch ply subfloor, then finish (cork/vinyl).
8. **Walls & ceiling cladding** — birch ply / cladding over the insulation, hiding the cable runs.
9. **Furniture carcasses** — bed garage, kitchen unit, wardrobe, shelves — built from birch ply to the model's dimensions. See [`/model`](../model).
10. **Electrical — second fix** — mount battery, MPPT, DC-DC, fuse block, sockets; connect the tails; commission + test.
11. **Water** — fit fresh/grey cans, pump, sink. See [04-water-plumbing](04-water-plumbing.md).
12. **Gas** — single hob, regulator, drop-out vent, leak test. See [05-gas](05-gas.md). (After electrics so alarms are live.)
13. **Soft fit** — mattress, bedding, blackout, curtains, storage, final EMF check.

**Never:** insulate over rust · clad before cables are run · skip the fan cut-in · trap moisture behind a non-breathable layer.

**Weight-check throughout** — log every heavy item against payload. See [07-weight-payload](07-weight-payload.md).
